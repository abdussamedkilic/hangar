# Hangar v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Steam, Epic ve Ubisoft oyunlarını tek bir koyu temalı Tauri masaüstü uygulamasında birleştiren, platform seçmeli başlatma yapabilen Hangar v1.

**Architecture:** Platform okuma, birleştirme ve SQLite mantığı Tauri'den bağımsız bir Rust kütüphanesinde (`crates/hangar-core`) durur ve fixture'larla test edilir. `src-tauri` ince bir katmandır: komutlar, olaylar ve platform linklerini açma. Arayüz React + TypeScript + Vite ile yazılır; tasarım spec'teki "5 · Kokpit + Vitrin" yönünü izler.

**Tech Stack:** Rust (edition 2021), Tauri 2, rusqlite (bundled), serde/serde_json, ureq, winreg (sadece Windows), React 18, TypeScript, Vite, Vitest, @tanstack/react-virtual, gsap, lenis.

**Spec:** `docs/superpowers/specs/2026-11-09-hangar-design.md`

## Global Constraints

- Hedef: Windows 11, x64; Linux/macOS hedef dışı. `hangar-core` Windows'a özel kodu yalnızca `#[cfg(windows)]` altında tutar ve Linux'ta derlenip test edilebilir kalır.
- Platformlar v1: `steam`, `epic`, `ubisoft`. GOG ve EA yok. Epic'te yalnızca kurulu oyunlar.
- Varsayılan başlatma platformu Steam; yoksa sıra `steam` → `epic` → `ubisoft`. Oyun başına seçilen platform kalıcıdır.
- Başlatma/kurma platform linkleriyle: `steam://rungameid/<appid>`, `steam://install/<appid>`, `com.epicgames.launcher://apps/<ns>%3A<itemId>%3A<appName>?action=launch&silent=true`, `uplay://launch/<id>/0`. Epic/Ubisoft "kur" düğmesi ilgili launcher'ı açar (`com.epicgames.launcher://store`, `uplay://`).
- Steam API anahtarı isteğe bağlı, SQLite'ta düz metin. Telemetri yok. Ağ yalnızca Steam Web API, Steam mağaza araması ve görsel indirme için.
- Veri ve önbellek: Tauri'nin `app_data_dir()` klasörü, yani `%APPDATA%\com.hangar.app\hangar.db` ve `...\covers\`. Spec'teki `%APPDATA%\Hangar` yerine bunu seçtim, çünkü Tauri'nin standart yolu bu.
- Kod akışı: tek kaynak bir GitHub reposu. Claude bulut çalışma alanında yazar, test eder ve push eder; kullanıcı Windows'ta `C:\Users\user\workdir\hangar` klasörüne klonlayıp `git pull` ile günceller.
- Görsel: yalnızca koyu tema; başlıklar Chakra Petch, gövde Figtree; zemin `#0f1318`, panel `#151a21`, yükselti `#1d242e`, çizgi `#252d38`, metin `#e8ebf0`, soluk `#8892a0`, vurgu `#f2a93b`, kurulu `#4fd18b`. `prefers-reduced-motion` desteklenir.
- Arayüz metinleri Türkçe. Büyük/küçük harf dönüşümü yerel ayardan bağımsız (`to_lowercase`, `toLowerCase`; asla `toLocaleLowerCase`).
- Karpathy kuralları: istenmeyen özellik yok, tek kullanımlık soyutlama yok, değişiklikler görevle sınırlı.
- Komutların çalıştığı yer: `cargo test -p hangar-core` ve `npm test` Claude'un Linux çalışma alanında; `npm run tauri dev` ve `npm run tauri build` kullanıcının Windows'unda.

## Review Focus

1. **Birden çok Steam kütüphanesi / silinmiş sürücü:** `libraryfolders.vdf` içinde var olmayan bir yol taramayı durdurmamalı; o kütüphane atlanmalı. (Task 3 testi)
2. **Oyun olmayan kayıtlar:** Steam araçları (`Steamworks Common Redistributables` 228980, `Proton`/`Steam Linux Runtime` adlıları), Epic DLC'leri (`AppCategories` içinde `addons`) ve yarım kurulumlar (`bIsIncompleteInstall: true`) listeye girmemeli. (Task 3, Task 4 testleri)
3. **Geçersiz Steam anahtarı ya da çevrimdışı:** kurulu oyunlar yine görünmeli; sahip olunanlar alınamadıysa arayüzde tek satır bir uyarı çıkmalı, uygulama çökmemeli. (Task 7 testi)
4. **Türkçe karakterler:** "İ/ı/ş/ğ" içeren başlık ve yollar bozulmamalı; ad normalizasyonu Türkçe yerel ayarda da aynı sonucu vermeli. (Task 6 testi, Task 9 testi)
5. **Launcher kurulu değil:** Epic klasörü ya da Ubisoft registry anahtarı yoksa sağlayıcı boş liste döner, hata vermez. (Task 4, Task 5 testleri)
